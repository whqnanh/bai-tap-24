Đăng Ký Domain & Kiểm Tra Bản Ghi DNS

Đăng ký tên miền DuckDNS, cấu hình bản ghi Record A trỏ về IP máy chủ và kiểm thử phân giải DNS bằng lệnh nslookup trên macOS.

1. Thông số kỹ thuật đã thiết lập

Thông số Giá trị thực tế Ý nghĩa
Tên miền đã cấp (Domain) mywebsite-hoanganh.duckdns.org Subdomain hoạt động trên máy chủ DNS toàn cầu
Loại bản ghi DNS Record A (Address) Ánh xạ tên miền sang địa chỉ IPv4
IP đích trỏ đến 113.185.75.163 Địa chỉ IP công cộng của web server
DNS Server kiểm tra Google Public DNS (8.8.8.8) Máy chủ DNS chuẩn cổng 53 để kiểm thử toàn cầu

2. Lệnh kiểm tra phân giải DNS

$ nslookup mywebsite-hoanganh.duckdns.org 8.8.8.8

Server: 8.8.8.8
Address: 8.8.8.8#53

Non-authoritative answer:
Name: mywebsite-hoanganh.duckdns.org
Address: 113.185.75.163

Xuất Bản Website Lên Nền Tảng GitHub Pages Bằng Git CI/CD

Khởi tạo kho lưu trữ GitHub whqnanh/my-portfolio, quản lý mã nguồn phiên bản bằng Git, tự động hóa quy trình triển khai bằng GitHub Actions và xuất bản website đa trang có chứng chỉ HTTPS.

1. Thông Số Triển Khai GitHub

Hạng mục Thông số chi tiết Trạng thái
GitHub Repository whqnanh/my-portfolio Public Repository
Nhánh phát hành (Branch) main / Thư mục / (root) Active
Hạ tầng Hosting GitHub Pages Fastly CDN toàn cầu Tốc độ phản hồi < 50ms
Chứng chỉ bảo mật SSL DigiCert TLS 1.3 Chuẩn HTTPS Enforced HTTPS ✓
Địa chỉ trang web https://whqnanh.github.io/my-portfolio/ ✅ Hoạt động 100%

2. Cấu Trúc Mã Nguồn Đã Xuất Bản

  • index.html: Trang chủ Portfolio giới thiệu bản thân sinh viên Nguyễn Hoàng Anh.
  • about.html: Trang tiểu sử, học vấn và các kỹ năng lập trình web.
  • contact.html: Trang liên hệ tích hợp biểu mẫu tương tác.
  • js/script.js & css/style.css: Giao diện hiện đại, responsive 100%.
